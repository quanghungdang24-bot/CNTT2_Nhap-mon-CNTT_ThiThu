# Website của cửa hàng văn phòng phẩm
## Giới thiệu
- Website Văn Phòng Phẩm là nền tảng trực tuyến chuyên cung cấp các sản phẩm văn phòng phẩm phục vụ *nhu cầu học tập, làm việc và sinh hoạt văn phòng*. Website giúp khách hàng dễ dàng *tìm kiếm, tham khảo giá cả và lựa chọn sản phẩm phù hợp* mà **không cần đến trực tiếp cửa hàng**.
## Bảng dữ liệu
| docs | Tài liệu của dự án |
| --- | --- |
| data | Lưu trữ dữ liệu của dự án |
| media | Lưu trữ hình ảnh của dự án |
